# 麻雀点数計算機 - ローカル利用ガイド

## 📁 ローカルでの起動方法

Node.js と npm を用意し、リポジトリのディレクトリで次のコマンドを実行してください。リポジトリの取得手順は [README](README.md) を参照してください。

```bash
# 依存関係をインストール
npm ci

# ローカルサーバーを起動
npm run serve
```

サーバーを起動したターミナルを開いたまま、ブラウザで http://localhost:3000/ にアクセスしてください。`index.html` が開き、点数計算や役選択、リセットなどの機能を利用できます。ビルド作業は不要です。

3000番ポートが使用中で別の URL が表示された場合は、ターミナルに表示された URL を開いてください。

- **機能**: PWA機能含む全機能利用可能

## 📄 index-local.html について

`index-local.html` は、従来のファイル名からアクセスした方に上記の起動方法を案内するためのページです。計算機能は含まず、自動転送もしません。案内に従ってサーバーを起動し、ターミナルに表示された URL を開いてください。

| ファイル | 用途 |
|---------|------|
| `index.html` | HTTP サーバー経由で利用するアプリ本体 |
| `index-local.html` | ローカルサーバーの起動手順を表示する案内ページ |

## ⚠️ ファイルを直接開く場合の制限

アプリ本体を `file://` で起動する方法には対応していません。`script.js` は ES Modules と相対インポートを使っており、ファイルを直接開くとブラウザの制限でモジュールを読み込めない場合があります。ローカルでも HTTP サーバー経由で `index.html` を利用してください。

## 📞 起動できない場合

1. リポジトリのディレクトリで `npm ci` が正常終了したか確認してください。
2. `npm run serve` を実行したターミナルのエラーと、ブラウザで開いた URL がターミナルに表示された URL と一致していることを確認してください。
3. 解決しない場合は、ブラウザコンソールのエラーを確認し、[GitHub Issues](https://github.com/tsudumikata/mahjong-calc/issues) に状況を報告してください。
