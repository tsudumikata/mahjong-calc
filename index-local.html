ローカル起動のご案内

麻雀点数計算機は、通常版の index.html をローカルサーバー経由で開いて利用してください。このページは起動方法の案内専用です。

ファイルを直接開いた場合

file:// から計算機を直接起動する方法には対応していません。Node.js と npm を準備し、このプロジェクトのフォルダーで次のコマンドを実行してください。

npm ci
npm run serve

サーバーを起動したまま、同じパソコンのブラウザで次のリンクを開いてください。

http://localhost:3000/ で計算機を開く

3000番ポートが使用中などで別のURLがターミナルに表示された場合は、そのURLを開いてください。

すでにサーバー経由で開いている場合

同じサーバーの計算機を開く

計算・役選択・リセットなどの機能は、通常版にまとまっています。
